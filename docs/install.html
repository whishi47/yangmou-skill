安装技能

安装阳谋师 Skill

一条命令即可把阳谋师安装为 Agent Skill，首页、案例画廊和 Flow 图会保持同步。

全局安装 
npx -y skills add whishi47/yangmou-skill --skill yangmou --agent codex --global --copy --yes

支持 Codex、Cursor、Claude Code、OpenCode 等 Agent Skills 运行环境。安装后直接在对话里描述一个博弈困境即可触发。
